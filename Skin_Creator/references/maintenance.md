# Maintenance only: context and execution cost

Do not load this file for ordinary Skin creation.

Use a short routing entry and natural stage modules. Keep the stable rules once; retrieve detailed schemas or a relevant recovery record only when needed. Recovery catalog/history are data, not default prompt content. The CLI dynamically imports recovery only for an explicit query, a command error or a failed contrast audit, and returns at most three matching cases.

Prefer `--format brief` for routine calls. Keep raw evidence on disk and report a compact result plus its path; load details after a failure. Preserve error reasons, revision hashes and validation limits. Do not hide failures to shorten output.

Resume stored sessions rather than re-inventorying unchanged geometry. Reuse the session language; system-language detection runs only for initial creation. Batch independent read-only work and let deterministic scripts handle arithmetic, hashes, image geometry and export. Keep dependent mutations sequential.

Measure output size and representative elapsed times before claiming improvement. Character counts are not billed token counts. Synthetic tiny-image timings exclude generation and live UI. Do not claim zero possible image-generation errors, assume caching is enabled, alter the user's model/provider, or remove acceptance and validation gates for speed.
